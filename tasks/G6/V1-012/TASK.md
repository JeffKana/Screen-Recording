## 滑窗口径（**必须写进用例注释**，指令 §3 #2）

1. **桶怎么分**：完全沿用 `Get-PerSecondStats` —— ffprobe `v:0` 的 `packet.pts_time` 按
   `[int][Math]::Floor()` 落整秒桶，桶内累加 `packet.size`（字节）；
   **跳过第 0 秒桶与最后一个桶**（编码器预热/收尾），一个桶换算 `bytes*8/1000` kbps。
2. **窗口怎么滑**：在「有效秒桶序列」上取**连续 5 个桶**为一个窗口，
   **逐秒滑动 1 桶**（不是 5 秒一跳）：第 1 窗 = 桶[0..4]，第 2 窗 = 桶[1..5]，…
   直到窗口右端到达最后一个有效桶。序列不足 5 桶则窗口数 = 0 → 判 FAIL（不判 SKIP）。
3. **窗口值**：窗内 5 桶字节总和 / 5 → 换算 kbps（即窗口平均码率），
   不是窗内单秒最大/最小。
4. **波动公式**：对所有窗口值取 `spread = (max - min) / avg`，判 `≤ 0.10`。
   沿用轮 32 的 spread 定义，只把「逐秒序列」换成「5 秒滑窗平均序列」。
5. **单秒挡板**：对**全部有效秒桶**（含滑窗未覆盖到的桶）逐个判
   `rate ≤ 2 × NominalKbps`（6000 → 12000）。取 `max` 输出，任一超标即 FAIL。
   **不得**因为滑窗 PASS 而跳过此判定（指令 §3 #3）。
6. `m3-04-cbr-nominal`（avg 偏差 ≤20%）、VBR 三条断言、60fps/15fps 断言**全部不动**；
   阈值字面量 `0.10` / `0.20` / `CapKbps*1.02` 保留。
