## 3. 已知限制是什么？

1. **「冲突」的判定是词法级的**：靠「否定实现的措辞 + 同一需求编号 + 有没有历史标注」三件事。
   写得含蓄的矛盾（例如正文说「尚未达成」而不用「未实现」）**扫不出来** —— 这是词法法的固有上限，
   脚本只能挡住最常见的那一类。
2. **只检查 `## 交付状态` 段**：卡片若把声明写在别的段（例如「元信息」里的状态字段），
   脚本看不到。S1-004 的抬头 `状态：**已实现**` 就是这种情形（本轮顺手改成了与状态段一致 ✓），
   但脚本不覆盖这一类 → 靠人工。
3. **历史标注的关键词是白名单**：`轮 N / 变更：/ 当时 / 此前 / 历史 / 回填 / 回扫 / 本卡自身 / 已由`。
   换一种说法写历史（例如「上一版」），会被判成冲突 → 误报（宁可误报也不漏报）。
