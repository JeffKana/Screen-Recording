## 2 · 一致性检查脚本

`verify/tools/card_consistency_check.py`：

- 扫描 `tasks/**/TASK.md`（本轮 30 张卡 ✓）；
- 解析 `## 交付状态` 段的声明行（`- M6-02: 已实现（…）`）✓；
- 正文里出现「有卡未实现 / 未实现 / 不能标 / 状态保持 / 尚未交付」且**提到同一需求编号**的句子 = 嫌疑行 ✓；
- 嫌疑行**或其所在小节标题**里出现「轮 N / 变更：/ 当时 / 此前 / 历史 / 回填 / 回扫 / 本卡自身 / 已由」→ 视为历史说明，不算冲突 ✓；
- 其余 → **冲突**，打印 `卡片:行号 [需求] 原文` 并**以退出码 1 拦下** ✓。
