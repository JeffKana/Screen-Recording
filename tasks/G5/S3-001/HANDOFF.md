## 1. 本轮改动面

| 位置 | 变化 | 下游影响 |
| --- | --- | --- |
| `MkvWriter::FlushPending()` | 新增公开方法 | S6 恢复流程无需改动；录制侧在暂停点调用 |

## 2. 下游需要接什么（轮 23 / T-16b）

- `--fail-write-after <N>`：在写第 N 帧后注入写失败，用于验证「录制中权限被收回」。
  目前该场景判 **BLOCKED**，因为 Windows DACL 对已打开句柄不生效。
- 复用 `MkvRecovery` 截断修复 + 提交到 `--fallback-dir`，退出码 16、输出 `fallback_path=`。
- G5-I8：恢复时强制后端不可用 → `backend_changed=1` + WARNING + 录制不中断 + 成片可播。

## 3. 已知限制

| 限制 | 影响 | 计划 |

| 暂停点不强制 DRAIN 编码器 | 崩溃丢失 ~1s 编码器缓冲 | 接受（DRAIN 会插 IDR 并可能破坏编码器状态） |

| ER-08 TDR 未覆盖 | M8-09 无法判定 | V1.5 |
