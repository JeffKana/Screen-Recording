## 约束

- Win32 原生（`Shell_NotifyIcon` + `RegisterHotKey`），Qt6 留给 V1.5。
- 默认热键：开始 `Ctrl+Alt+F9`、暂停/继续 `Ctrl+Alt+F10`、停止 `Ctrl+Alt+F11`；
  实测 `Ctrl+Alt+S` 在本机被其它程序占用，故默认值避开常见组合。
- 热键回调只产生命令；UI 状态一律由 `StateSnapshot` 驱动，不做乐观更新。
- 热键注册失败必须可见（窗口状态栏 + 托盘提示 + 日志），且不阻断其它热键。
- 非暂停状态下控制通道断开不得中断录制（沿用轮 26 语义）。
- 应用退出前必须等 Recorder 子进程收尾；不得留下 `sr-recorder` 进程。
- 托盘图标/菜单置灰/最小化属人工项，截图单列，不计入自动化 PASS。
