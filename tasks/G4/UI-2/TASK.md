## 约束

- 剩余时长公式只在 `src/core/util/DiskEstimate` 实现，`StorageGuard` 与 UI 不得各写一遍。
- 可写性以 Recorder 的 exit 13 为准；UI 的 `EnsureDirectoryWritable` 只做提前提示。
- 命名模板在 UI 侧展开，Recorder 只收最终路径（不改 IPC 契约）；展开后仍走「不覆盖」规则。
- 悬浮条必须 `WS_EX_TOPMOST | WS_EX_NOACTIVATE`，点击不得把焦点从被测窗口抢走。
- `src/app` 仍只链接 `sr_ipc` / `sr_core`；不持有采集/编码/封装对象。
- 采集优先级本轮不动：WGC/DXGI 的选择等活跃本机会话复测后再评估。
