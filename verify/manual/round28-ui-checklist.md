# 轮 28 UI-2 人工验收清单

## 环境

- Windows 11，显示 1920×1080；默认热键 `Ctrl+Alt+F9/F10/F11`。
- 启动：`build-msvc\bin\Release\sr-ui.exe`（不隐藏）。
- 截图保存在本目录：`round28-*.png`。

## 1. 剩余可录时长（M2-09#2）

| 步骤 | 预期 |
| --- | --- |
| 启动应用，观察状态栏 | 显示「就绪。输出目录 … · 剩余可录 hh:mm:ss」 |
| 开始录制，观察 3 秒 | 计时每秒递增；剩余可录每秒刷新（不跳变、不归零） |
| 暂停 3 秒 | 计时冻结；剩余可录仍按磁盘刷新 |
| 恢复 | 计时从冻结值继续，不补跳 |

自动化已断言：公式误差 0%、日志刷新 1000ms；本条只确认视觉可读性。

## 2. 保存路径（M5-01）

| 步骤 | 预期 |
| --- | --- |
| 点击「保存路径…」，选择一个普通目录 | 对话框关闭，状态栏输出目录立即更新；INI 写入 `[output] dir=` |
| 重新启动应用 | 状态栏仍是该目录（持久化） |
| 选择一个只读/拒绝写入的目录（或用 `icacls` 去掉写权限） | 弹出「保存路径不可写: …」；旧路径不变；INI 不变 |
| 录制时权限被收回 | Recorder 以 exit 13 退出；状态栏显示 code=13；UI 只做提前提示 |

自动化已断言只读 ACL → exit 13 + reason + INI 不变；本条确认对话框文案与位置。

## 3. 命名模板（M5-02 / AC-10）

| 步骤 | 预期 |
| --- | --- |
| 打开「设置…」 | 可见「命名模板」输入框与变量提示 `{date} {time} {source} {app} {index}` |
| 输入 `ac10_{index}` 保存 | 关闭后重启仍保留（INI `[output] template=`） |
| 同一模板 1 秒内连录两次 | 生成 `ac10_001.mkv` 与 `ac10_002.mkv`，均可播放 |
| 模板含 `<>:"/\|?*` 或控制字符 | 落盘文件名自动替换为 `_`，不产生非法路径 |

自动化已断言 AC-10 两个文件均可解码；本条确认设置窗口的可用性。

## 4. 悬浮工具条（M2-08）

| 步骤 | 预期 |
| --- | --- |
| 开始录制 | 右下角出现悬浮条：计时、剩余、暂停/继续、停止、隐藏 |
| 点击其他窗口后再点悬浮条按钮 | 焦点留在被测窗口（不抢焦点）；暂停/继续/停止生效 |
| 按住悬浮条空白处拖动 | 位置跟随鼠标；松手后保持 |
| 点「隐藏」 | 悬浮条消失；托盘菜单「显示悬浮工具条」可恢复 |
| 录制结束 | 悬浮条自动隐藏；下次开始重新出现 |
| 按钮态 | 录制中「暂停/停止」可用；启动中/空闲时置灰；暂停后文字变「继续」 |

自动化已断言 exstyle `TOPMOST|NOACTIVATE`、NCHITTEST=HTCAPTION、MOUSEACTIVATE=MA_NOACTIVATE、
按钮点击/隐藏/托盘恢复；本条确认拖动与视觉层级。

## 5. 托盘 / 最小化（沿用轮 27）

| 步骤 | 预期 |
| --- | --- |
| 托盘右键 | 「开始录制」在录制态置灰；「设置…」「显示悬浮工具条」可用 |
| 最小化 | 主窗口从任务栏消失；托盘还在；双击恢复 |
| 录制中关闭应用 | 先 Stop，成品提交，进程退出，无残留 |
