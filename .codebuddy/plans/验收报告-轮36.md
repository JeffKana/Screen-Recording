## 1. 我的错误（先说这个）

上一轮我给的判据①是 `ffmpeg -f null -vsync 0`，并声称「复跑 0 条警告」。本轮复测：

```
$ ffmpeg -ss 15990 -t 60 -i lt01-8h.mkv -f null -vsync 0 -
Unrecognized option 'vsync'.
Error splitting the argument list: Option not found
exit=-1414549496   ← 命令失败，stderr 里当然没有 DTS 警告
```

**我的「0 条」是命令失败导致的假阴性**，和 D-58（旧漂移算法假报 −2s）是同一类错误——只是这次出在验收侧。
执行方改用的「显式剔除并计数」是对的，我采纳他们的实现，裁定文本按下面修订：

> **M6-09「完整可播」判据（修订版）**
> ① `ffmpeg -v error -i F -f null -` 退出码 0，且 stderr 中**没有解码器错误**（`[h264]`/`[aac]` 的 error 级）；
> ② `-f framecrc`：帧数 = `frames_encoded`，DTS 严格递增、无倒退；
> ③ `[null @ ...] non monotonically increasing dts to muxer` 单独计数、**不计入失败**——它由落盘端 1/30 时基对 33.37ms 帧间隔取整产生（本轮实测：PTS 无重复、DTS 严格递增、864,000 帧齐全）。
