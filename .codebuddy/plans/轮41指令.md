## 2. R1 的修法要点

现在失败形态是「四个字段全 0 → 误差异 100% → FAIL」，这是**用缺失数据算结论**，与 D-58 同族。正确语义三档：

1. 字段齐全 → 正常算误差，判 ≤20%；
2. 字段缺失一次 → **重试一次**（快照/输出偶发截断）；
3. 仍缺失 → 输出 `数据未取到：estimated_record_seconds 缺失`，标 **SKIP** 并计入「环境/取数失败」，**不参与 PASS 统计**。

另外查一下为什么会有残留：上一段 M8-04 的录制进程可能在 `--record` 返回后仍持有单实例锁数十毫秒，这次拿到的可能是 `exit=2/3`（单实例拒绝）——把 exit 码也打进断言文案，下次一眼能看出。
