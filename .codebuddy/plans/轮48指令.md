## P0-1 修 `g5_closeout` 的数量写死（先红后绿）

现状：`m6-04-02-hw-unavailable-with-reason` 断言「不可用行 == 3」，产品诚实标了 4 行就红。

改成三条：

1. `nvenc-h264` / `qsv-h264` / `amf-h264` **都在** unavailable 列表内；
2. **每一行** unavailable（不限条数）都有非空 `reason`；
3. 反向：人为抹掉任意一行 reason → **必须 FAIL**。

红线：不许把断言改成"≥3"了事——那仍然放得过"新加的项没写原因"。

## P0-2 M3-09#1 MP4 writer 主体

**范围（本卡只承诺到这里，别一口气吞 faststart）**：

- 新增 `src/mux/Mp4Writer`（与 `MkvWriter` 并列，不改 MKV 行为）；
- 写出可播 MP4：`ftyp` + `mdat` + `moov`（**moov 可后置**）；
- 轨道：1 路 H.264 + 1 路 AAC；sample table（`stts/stsz/stsc/stco/stss`）正确；
- 入口 `--format mkv|mp4`（默认 mkv，保持现有行为）。

判据：

| # | 命令 | 期望 |
| --- | --- | --- |
| 1 | `ffprobe -v error -show_entries format=format_name,duration` | `format_name=mov,mp4,...`，duration = 录制秒数 ±0.2s |
| 2 | `ffmpeg -v error -i out.mp4 -f null -` | exit 0，无 error 级输出 |

- `--format mkv|mp4` 只影响封装器选择，**不得**改变状态机迁移；

## 注意事项

1. **MP4 的坑在 sample table**，不在 box 顺序：`stts` 的 delta 必须来自真实 DTS 差，`stss` 只标 IDR；先写一个 5s 样本让 `ffprobe -show_streams` 全字段对齐，再谈 faststart。
2. 时间基换算（90kHz）会引入 ±1 tick 误差，**别用 1/fps 累加**去补——那会在长录制上漂。
3. 不要动 MKV 的 `FlushPending` / 恢复语义；两份封装器共用 `.part` 约定即可。
4. `g5_closeout` 属 V1-004 卡的文件域，本轮你**可以改**（已明确授权），但只改断言与反向用例，别改其它断言。
5. 5 连 `g5_format` 会占约 10 分钟，放在最后跑，避免与 MP4 调试互相干扰。
