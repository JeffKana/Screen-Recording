## 2. 8h 判定细则（照这个算，别自创）

| 项 | 算法 |
| --- | --- |
| 内存 | `peak_ws_mb` 的全程最大值 − 开录后 9~11 分钟窗口内最大值；判据 ≤50MB。同时给 8 个小时段均值，判断有无单调爬升 |
| 句柄 | 以 9~11min 为基线，全程峰值增幅 ≤10%（基线约 483~498） |
| 时长 | `duration_s ≥ 28,790`（28,800−10）；同时核对 `frames_encoded` 与 `expected` |
| 可播 | `ffprobe` 全流 + `ffmpeg -f null -` 全片解码零错误；不要只解前 60s |
| 漂移 | 16 点，每点读 `[At−10, At+10]`，取 `pts ≤ At+0.5` 的最后包，音视频各一；报告**最差点**与中位数 |
| 丢帧 | `frames_dropped / frames_expected`；与日志 `dropped=` 的最大值交叉核对 |
