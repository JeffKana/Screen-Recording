## 2. 三件裁定

### 2.1 `docs/01` M3-09「MP4（默认）」与实现「默认 MKV」

需求原文明确写了 MP4 默认，实现按我的卡做了 MKV 默认。**这条冲突是我写的卡造成的，我认。**

裁定：**改 `01` 措辞，V1.0 默认 MKV**，理由是产品侧事实：

- MP4 的**崩溃恢复未适配**（`.part` + 截断修复只对 MKV 成立）；
- 默认切 MP4 = 默认路径上失去 M6-05 的恢复能力，这是用一个"默认值"换一个"硬需求倒退"。

落地要求（轮 49）：`01` M3-09 改为「容器格式：MKV（V1.0 默认）与 MP4（`--format mp4`）」+ 变更记录，并写明「MP4 崩溃恢复适配后（V1.1）再切默认」。

### 2.2 `--format` 非法值 `exit 2` 不在契约表

**我回写**：`CONTRACT.md §18.2` 增加一行 `2 | 参数错误（未知选项/非法取值） | 无产物 | 打印 usage，不重试`。本轮验收 PR 已包含。

### 2.3 M3-09#1 faststart / #2 多音轨 / UI 扩展名

- faststart、多音轨 → 轮 49（原计划，不变）；
- **UI 输出名固定 `.mkv`** → 与 `--format` 不一致，轮 49 至少做到"扩展名跟随格式"，否则用户 `--format mp4` 拿到 `.mkv` 文件；
- **MP4 崩溃恢复** → 登记 `docs/22`，标 V1.1 前置，不在 V1.0 冒充。
