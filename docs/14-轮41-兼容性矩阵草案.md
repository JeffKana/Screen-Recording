## 1. 口径（先写清楚，避免「没跑过却填了结果」）

1. **等级**：`必测` = 发布判据 `docs/05 §7.2` 第 5 条要求 100% 覆盖；`抽测` = 要求 ≥80%。
2. **结果列四态**：`PASS / PARTIAL / FAIL / 未测`。未跑过的格子一律 `未测`，
   不写「预估通过」「应当可用」等推断。
3. **每行判据三件套**（`docs/11b §6`）：录一段 60s 素材 → 抽帧比对 → 音画偏差。
   「跑起来没崩」不算结论。
4. **已测项的定义**：轮 41 的回归产物只是**旁证**（未跑三件套），标「降级旁证」；
   轮 42 的 `g5_r42_matrix.ps1` 才按三件套专项实测，标「实测 PASS」并写明降级边界
   （物理双屏机器用 `--display 0` 只采主屏代表单屏）。两者不混。
5. 本机环境（实测，非推断）：`Win11 家庭版 中文版 build 26200`、双屏 `1920×1080 ×2`、
   DPI 未显式设置（系统默认 100%）。该机器只能对应矩阵中的**一格**。
