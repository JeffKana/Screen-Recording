## 引用约定

1. `docs/11b §6` = 兼容性矩阵三件套口径；历史卡里写成 `docs/11 §6` 的，一律按 `11b` 解读。
2. 已裁定的文书命名为「裁定记录」；「裁定申请」只用于**尚未裁定**的文书。
   `verify/tools/card_consistency_check.py` 的 F2 规则据此报警：正文引用待裁定的
   `docs/1x-*裁定申请` 且卡片声明「已实现」 → 冲突（验收报告-轮41 §5 F2）。
3. `docs/09` 是 `python verify/tools/coverage_report.py --write` 的生成物；
   改 `docs/01` 的验收要点后必须重跑 `--write`，否则 `--check` 报 stale。

## 一致性自检

```powershell
# 编号唯一（取文件名前缀，忽略 INDEX.md）
Get-ChildItem docs -File -Filter '*.md' |
  Where-Object { $_.Name -ne 'INDEX.md' } |
  ForEach-Object { ($_.Name -split '-')[0] } |
  Group-Object | Where-Object Count -gt 1
# 期望：无输出
```
