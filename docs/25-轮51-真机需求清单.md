## 2. 到位后的统一动作（四条共用）

1. **先记指纹**：`VERSION.txt` 的 `source_fingerprint` + 两个 exe 的 SHA256；不同构建的数据不可横比。
2. **同口径**：判据、采样窗口、统计方式照 `docs/05` 原文，不因机器换了就换度量。
3. **原始输出入库**：`tasks/G6/<当轮卡>/artifacts/`（该目录不入库，验收方需自行重跑）或写进 `EVIDENCE.md` 的命令 + 输出行。
4. **没测完不写"通过"**：四条各自独立判定，缺一条就写"未测"，不拿"同族机器"顶替。
5. **优先顺序建议**：`M6-08#1`（混合显卡最普遍）→ `M6-04#1`（N 卡最容易借到）→ `M6-01#1`（要独占窗口，得约时间）→ `M6-05#1`（三台 OS 最麻烦）。
