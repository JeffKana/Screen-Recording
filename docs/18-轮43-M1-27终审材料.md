## 2. 黑屏不可复现的环境依据（实测，非推断）

验收方轮 40 独立重跑记录 + 执行方复核，本机注册表/策略：

```
ConsentPromptBehaviorAdmin = 0        # 管理员同意提示不落安全桌面
PromptOnSecureDesktop      = 0        # 未启用安全桌面
```

- UAC 弹窗不切换到 Winlogon 安全桌面 → WGC / DXGI 桌面复制都能正常采到弹窗，
  「黑屏」现象在本机**物理上不可复现**。
- 有力旁证：同场景 `PrintWindow` 对提权窗口 `frames=0`、`record_exit=4`
  （UIPI 拦截），说明提权窗口确实属于更高完整性级别、受 UIPI 保护；
  但**这不等于**「安全桌面黑屏」被验证通过，只是解释为什么本机的替代路径也拿不到画面。
- 结论：既不能判 PASS，也不能判 FAIL；按 `docs/05 §7.2` 登记为 BLOCKED 发布例外。

## 3. 人工复测步骤（轮 44 / 有安全桌面机器时执行）

1. 准备一台 **Win11 Pro/Enterprise**、开启 UAC 安全桌面的干净机：
   ```
   HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System
     ConsentPromptBehaviorAdmin = 2   （或 5，非 0）
     PromptOnSecureDesktop      = 1
   ```
   改完重启，用 `whoami /groups` 确认当前账户为管理员但非 SYSTEM。
2. 用**发布包**（`SR_TEST_HOOKS=OFF`）安装并启动 `sr-ui.exe`，
   确认主窗口出现「（未提权：UAC 提权窗口可能黑屏）」提示。
3. 点击「以管理员身份重启」→ UAC 弹窗出现时开始录屏 ≥10s，
   期间移动弹窗、点击「是」，保存成片。
4. 抽帧检查：
   - 弹窗区域是否全黑（黑屏现象是否复现）；
   - 桌面其它区域是否正常；
   - `ffprobe` 双轨 + `ffmpeg -f null` 解码零错误；
   - `record_exit` 与 UI 日志的 `elevated=1`。
5. 记录：OS build、UAC 两项注册表值、`converter` / `backend`、成片路径与 SHA256、
   抽帧截图；填进 `docs/14` 对应矩阵格并给 PASS/PARTIAL/FAIL。
6. 若复现黑屏 → 按 `docs/05 §7.2` 判 EX-01 不成立，M1-27#1 保持「有卡未实现」，
   V1.0 不得发布；若不复现且提示/入口有效 → 由验收方裁定是否可终审关闭。

### 3.1 复测条件与判定门槛（轮 44 定稿新增）

复测**必须同时满足**下列前提，缺一条即判「条件不成立」，不得给 PASS：

| # | 条件 | 核验方式 |
| --- | --- | --- |
| 1 | 干净机 Win11 Pro/Enterprise，`ConsentPromptBehaviorAdmin ∈ {2,5}` 且 `PromptOnSecureDesktop=1`，已重启 | 注册表截图 + `whoami /groups` |
| 2 | 使用**发布包**（`SR_TEST_HOOKS=OFF`）而非开发构建 | `sr-recorder.exe --version` 含 `test_hooks=0` |
| 3 | UAC 弹窗出现期间确实在录（`record_exit=0`、成片 ≥10s、双轨、解码零错误） | stdout + ffprobe + `ffmpeg -f null` |
| 4 | 抽帧覆盖「弹窗出现 / 移动 / 点击是」三个阶段 | 至少 3 张截图 + 抽帧命令 |

判定门槛：

- **弹窗区域全黑且其它区域正常** → 黑屏现象复现，EX-01 **不成立**；
  M1-27#1 保持「有卡未实现」，V1.0 不得发布，需排期修复。
- **弹窗区域可见且提示/入口有效** → 由验收方裁定是否可终审关闭 EX-01，
  并按 `docs/05 §7.2` 六条逐条复核；执行方不自评。
- **环境前提任一不满足** → 维持 BLOCKED，EX-01 继续有效，不得写成 PASS。
