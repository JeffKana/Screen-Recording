版本分布解读：

- **V1.0 集中度 66 条（45.8%）**，且高度集中在 M1/M2/M3/M6/M8 五个模块 —— 印证「MVP 只做录制成功与录制可靠」的取舍。
- **M4 编辑模块 V1.0 为 0 条**，是刻意的产品决策：剪辑类功能对录制成功率零贡献，但会消耗大量工程预算。
- **V2.0 的 30 条里有 10 条在 M4**，第二增长曲线押在「编辑」而非「录制」。

## M1 · 采集能力

覆盖画面源（全屏 / 区域 / 窗口 / 摄像头）与音频源（系统声音 / 麦克风 / 混音）的采集。

| --- | --- | --- | --- |

| M1-02 | 多显示器枚举与指定显示器录制 | 接入 3 台显示器时可列出 3 个可选项并标注分辨率与位置编号；选中后仅录制该屏内容 | V1.0 |

| M1-04 | 区域录制：鼠标拖拽框选任意矩形区域 | 框选过程中实时显示宽×高像素值；松开后选区与拖拽轨迹误差 ≤ 1px | V1.0 |

| M1-07 | 单窗口录制：枚举可见顶层窗口并支持点选，含传统 Win32、UWP 与子对话框 | 窗口列表排除自身界面与系统隐藏窗口；选中 Excel 主窗口时录制内容为该窗口客户区 | V1.0 |

| M1-10 | 窗口最小化处理策略：最小化时按「冻结最后一帧 / 跳过该时段 / 暂停录制」三选一 | 三种策略均可配置；选「冻结」时最小化 5 秒后成片该段为静止画面且时长连续 | V1.5 |

| M1-14 | 摄像头热插拔处理：录制中拔出与插入 | 拔出后 PiP 位置显示占位图或自动隐藏，录制不中断；重新插入后 3 秒内自动恢复 PiP | V1.5 |

| M1-17 | 麦克风采集与电平指示 | 开录前显示实时电平条；说话时电平条有响应，静音时回落至底部 | V1.0 |
| M1-18 | 混音输出：系统声音与麦克风混合为单条音轨 | 同时播放音乐与说话，成片可清晰听到两者；单轨模式下文件仅含 1 条音轨 | V1.0 |
| M1-19 | 双轨输出：系统声音与麦克风分别保留为独立音轨 | 成片容器含 2 条音轨，用播放器可单独切换听到各自的源 | V1.5 |
| M1-20 | 音频独立增益与静音：两路各自音量滑块（0~200%）、独立静音开关 | 拖动滑块实时生效（试听可感知）；静音某一路后成片该路完全无声且另一路不受影响 | V1.0 |
| M1-21 | 静音期音频时间轴连续性：Loopback 无数据包时主动填充静音样本 | 录制过程中系统静音 10 秒再恢复播放，成片音画始终同步、总时长与视频一致，无进度条跳跃 | V1.0 |
| M1-22 | 麦克风降噪与自动增益：噪声门、环境降噪、AGC | 开启降噪后键盘敲击声明显减弱；开启 AGC 后小声说话与大声音量差距缩小 | V2.0 |
| M1-23 | 音画同步手动偏移校准：-500ms ~ +500ms 步进 10ms | 设置 +200ms 后成片中音频相对视频延后 200ms（±20ms 内），设置可持久化 | V1.5 |
| M1-24 | 光标采集开关：可选择是否将鼠标指针写入成片 | 关闭后成片任何位置都不出现鼠标指针；开启后指针位置与操作一致、无残影 | V1.0 |
| M1-25 | DRM / 受保护内容检测与提示 | 采集到持续纯黑画面且检测到受保护内容标识时，界面提示「该内容受版权保护无法录制」，不静默产出黑屏文件 | V1.5 |
| M1-26 | HDR 采集与色调映射 | HDR 显示器录制的成片在 SDR 播放器上高光不死白、暗部有细节；色彩偏差肉眼不可辨 | V2.0 |
| M1-27 | UAC 提权窗口采集限制提示 | 非管理员运行时录制 UAC 提权窗口，成片该窗口区域为黑屏，且开录前/录制中给出明确提示与「以管理员身份重启」入口 | V1.0 |
| M1-28 | 录制中摄像头画中画热开关 | 录制中通过工具条关闭 PiP，此后画面不含摄像头而前段保留；录制不中断、时长连续 | V1.5 |

> **M1 边界场景备注**
> - 独占全屏（游戏）场景由 DXGI Desktop Duplication 补充路径覆盖，属 M6-07/M6-08 的性能与兼容范畴，需求落在 M6。
> - 采集源在录制中丢失（显示器拔出、分辨率变更）不在 M1，归入 M8-10 异常处理。

## M2 · 录制控制

覆盖录制的生命周期控制、触发方式、状态反馈与防误操作。

| 编号 | 需求描述 | 验收要点 | 版本 |
| --- | --- | --- | --- |
| M2-01 | 开始录制：一键从当前配置进入录制态 | 点击/热键后 ≤ 1.5s 内进入录制态并出现录制指示；首帧不晚于指示出现后 500ms | V1.0 |
| M2-02 | 暂停与恢复：暂停期间不采集不入盘，暂停时长不计入成片 | 录制 5s → 暂停 10s → 恢复录制 5s，成片时长约 10s（不含暂停段），暂停期间画面不出现 | V1.0 |
| M2-03 | 停止并封装：停止后生成可播放的最终文件 | 停止后 3s 内（60s 素材）生成 MP4，双击可播放，时长与录制计时一致（误差 ≤ 0.5s） | V1.0 |
| M2-04 | 倒计时开录：可选 0 / 3 / 5 / 10 秒，倒计时期间可取消 | 选 5s 时界面显示 5→4→3→2→1 且带取消入口；取消后不产生任何文件 | V1.0 |
| M2-05 | 全局热键：默认开始/暂停/停止快捷键，工具失焦时仍生效 | 切到浏览器后按下热键仍能开始与停止录制；热键响应 ≤ 200ms | V1.0 |
| M2-06 | 热键自定义与冲突检测 | 录入已被其它程序占用的组合键时提示「该热键已被占用」并拒绝保存；自定义后立即生效且持久化 | V1.0 |
| M2-07 | 托盘菜单控制：托盘图标提供开始/暂停/停止/打开目录/设置 | 所有菜单项状态与当前录制状态一致（录制中「开始」置灰）；点击后行为与主界面一致 | V1.0 |
| M2-08 | 录制中悬浮工具条：显示计时、暂停/恢复、停止、麦克风与摄像头开关 | 工具条始终置顶且可拖动位置；录制中不遮挡选区关键内容（可一键隐藏）；按钮状态实时正确 | V1.0 |
| M2-09 | 录制时长与剩余可录时长显示 | 录制计时精确到秒且与成片时长一致（误差 ≤ 0.5s）；剩余时长随写盘速度动态刷新，误差 ≤ 15% | V1.0 |
| M2-10 | 录制状态机与非法操作防护 | Idle/Countdown/Recording/Paused/Stopping/Recovering 六态互斥；录制中重复点「开始」不产生第二个文件或第二路采集 | V1.0 |
| M2-11 | 自动分片：按录制时长或单文件大小自动切分 | 设为「每 10 分钟分片」录制 31 分钟得到 4 个分片且总时长连续无丢失帧；分片可在文件列表一键合并 | V1.5 |
| M2-12 | 单实例运行与重复启动防护 | 再次启动时激活已有窗口而非开启第二个实例；两实例同时录制同一区域的情况不可发生 | V1.0 |
| M2-13 | 录制中主界面隐藏 / 最小化到托盘 | 选择「最小化」后主窗口从任务栏消失、托盘保留；再次点击托盘恢复原位置 | V1.0 |
| M2-14 | 开录前自检：磁盘空间、编码器可用性、采集源可访问、音频设备存在 | 任一项不通过时阻止开录并指出具体原因；自检耗时 ≤ 500ms，不表现为卡顿 | V1.0 |
| M2-15 | 提示音与语音提示开关：开录/停止/暂停的听觉反馈 | 开启后开始与停止有可区分提示音；该提示音不录入成片音频 | V2.0 |
| M2-16 | 录制中参数锁定 | 录制中分辨率/帧率/编码器/保存路径等关键参数置灰不可改；音量类参数仍可实时调节 | V1.0 |

> **M2 设计取舍**
> - 暂停采用「停止采集 + 断点续写」而非「继续采集后丢弃」，避免暂停期间仍占用 GPU 与磁盘带宽（M2-02 验收即以此为准）。
> - 分片（M2-11）与崩溃恢复（M8-01）共用同一套分片写入机制，V1.0 必须先具备该机制，只是默认不开启分片轮转。

## M3 · 画质与参数

覆盖输出规格、编码参数、编码器选择与参数的可用性保障。

| 编号 | 需求描述 | 验收要点 | 版本 |
| --- | --- | --- | --- |
| M3-01 | 输出分辨率：原始分辨率、1080p、720p、480p、自定义宽×高 | 选 720p 录制 1080p 屏幕，成片实际分辨率为 1280×720；选「原始」时与采集源分辨率一致 | V1.0 |
| M3-02 | 尺寸对齐与缩放策略：宽高强制偶数（YUV420 要求），缩放提供「等比 + 黑边」与「拉伸」 | 输入 1365×767 时输出自动修正为 1364×766 且提示已调整；等比模式下画面不变形 | V1.0 |
| M3-03 | 帧率配置：15 / 24 / 25 / 30 / 60 / 自定义（1~144） | 选 60fps 录制动态画面，成片用帧率检测工具测得 59~60fps；选 15fps 时实际帧数不超过配置值 | V1.0 |
| M3-04 | 码率控制模式：CBR（固定码率）与 VBR（平均码率 + 峰值上限） | CBR 模式下**全片平均码率**与标称偏差 ≤10%，且**任意单秒**码率不超过标称的 2 倍。VBR 按三条验收（① 指定运动源 20s、标称 6000/峰值 9000 下逐秒均值偏差 ≤20%，② 任意内容单秒峰值 ≤ 配置峰值上限，③ 静态桌面只记录实测值不判定），细则见 05 §2.4 | V1.0 |
| M3-05 | 编码器自动探测与选择：列出本机可用硬件编码器及软编 | 界面显示实际可用列表（如 NVENC / QSV / AMF / x264）；不可用项不出现或标注不可用原因 | V1.0 |
| M3-06 | 硬编优先、软编确定性回退 | 硬编初始化失败时自动切软编且录制不中断，界面提示已回退；强制指定硬编但不可用时开录前即报错 | V1.0 |
| M3-07 | H.264 编码输出 | 成片为 H.264 High Profile，主流播放器与剪辑软件均可正常解码 | V1.0 |
| M3-08 | H.265 / HEVC 编码输出 | 成片为 H.265，同画质下体积比 H.264 小 ≥ 30%；不支持硬编 HEVC 的设备自动回退 H.264 并提示 | V1.5 |
| M3-09 | 容器格式：MP4（默认）与 MKV | MP4 优先 faststart 布局；MKV 支持多音轨与更长容错；切换格式不影响录制流程 | V1.0 |
| M3-10 | 画质预设档位：极致 / 高清（默认）/ 标准 / 省空间，一键联动分辨率、帧率、码率 | 切换档位后各参数联动变化且可在高级面板单独覆盖；预设值在界面可见 | V1.0 |
| M3-11 | 关键帧间隔（GOP）设置：自动 / 固定秒数 | 设为 2s、30fps 时成片关键帧间隔约 60 帧（±2 帧）；自动模式下动态画面自动缩短 GOP | V1.5 |
| M3-12 | 音频参数：采样率 44.1k/48k、码率 96~320kbps、声道 单声道/立体声 | 设为 48kHz/192kbps 立体声后，成片音频流参数与设置一致（可用 mediainfo 校验） | V1.0 |
| M3-13 | CRF / CQP 质量模式：以质量为目标而非码率 | 选 CRF 23 录制静态画面与动态画面，静态段码率明显低于动态段而画质稳定 | V1.5 |
| M3-14 | 参数校验与预估：文件体积、资源占用、编码耗时预估，超限时告警 | 录制前显示「预计 1 分钟约 XX MB」；预估误差 ≤ 30%；超出设备能力（如 4K60 硬编）时给出降级建议 | V1.5 |
| M3-15 | 定点丢帧策略：性能不足时按时间戳丢帧而不改变时间轴 | 人为制造 GPU 压力导致实际 45fps（配置 60fps），成片时长仍准确、音画同步、无加速播放现象 | V1.0 |
| M3-16 | 10bit / 色彩空间设置：NV12（默认）与 P010，BT.709 / BT.2020 | 10bit 输出成片位深为 10bit；色彩标注正确，播放器识别为对应色域 | V2.0 |
| M3-17 | AV1 编码输出 | 支持 AV1 硬编的设备可输出 AV1；不支持时标注不可用，不提供不可用选项导致开录失败 | V2.0 |
| M3-18 | 配置文件导入 / 导出 | 导出的配置文件可在另一台机器导入并完整还原参数；版本不兼容时给出提示 | V2.0 |

> **M3 关键约束**
> - 所有编码参数必须在**编码器能力探测之后**才允许设置（M3-05），避免出现「界面可选但开录失败」的组合。
> - 帧率上限、分辨率上限、码率上限由硬件编码器 SDK 的能力查询结果决定，硬编与软编的上限分开维护。

## M4 · 编辑与导出

覆盖轻量时间轴编辑、画面标注、字幕与导出。**本模块 V1.0 无交付**，编辑能力整体从 V1.5 开始。

| 编号 | 需求描述 | 验收要点 | 版本 |
| --- | --- | --- | --- |
| M4-01 | 时间轴预览与播放：波形 + 缩略图轨道，可拖动定位 | 拖动进度条定位误差 ≤ 1 帧；预览播放流畅（≥ 30fps），音频与画面同步 | V1.5 |
| M4-02 | 裁剪：掐头去尾与中间区间删除 | 删除 [00:10, 00:20] 区间后成片总时长减少 10s，拼接处无花屏、无爆音 | V1.5 |
| M4-03 | 无损裁剪：关键帧对齐的快速裁剪，不重编码 | 仅掐头去尾的裁剪在 30s 内完成且画质无二次损失；裁剪点自动吸附到最近关键帧并提示 | V2.0 |

> **M4 与 M5 的边界**
> - 「导出」负责**重新生成**一个文件（M4-13~M4-17），走完整编码管线。

> - 二者共用底层转码能力，但入口与参数暴露面不同，不合并为同一功能。
