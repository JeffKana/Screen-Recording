- 类型：**测法缺陷 / 判据口径**，非实现缺陷
- 影响需求：M8-05#1（覆盖表当前「已实现」，轮 40 验收方判 PARTIAL + 不稳定）
- 裁定方：验收方 / 规划侧（本文只给实测数据与选项，执行方不自定测法）
- 关联：`docs/12-轮34-VBR测法裁定记录.md`（同类先例）、验收报告-轮40 §2（R1）

## 1. 背景

轮 40 验收方独立重跑 `g5_storage.ps1` ×3：`12/1`、`13/0`、`13/0`。
其中一次 `FAIL` 是**假失败**——`$estOut` 为空时四个字段取 0，用「没取到数据」算出 100% 误差。
验收方把根因定位在「取数前置与失败语义」，产品侧数值 0.1~0.2% 没问题。

轮 41 R1 按令修复：清残留 + 等 ≤2s、字段三档语义、缺失→重试→SKIP「数据未取到」、
`record_exit` / `attempts` 进断言文案，**误差 ≤20% 判据一字未改**。

## 2. 复测事实（`tasks/G6/V1-002/artifacts/R1-five-runs.txt`）

命令：`pwsh -File verify/cases/g5_storage.ps1`，连跑 5 次。

| 次 | 结果 | 估算 | 实测口径 | 误差 | 实测码率 | record_exit | attempts |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 13 PASS / 0 FAIL | 19,333s | 18,463s | **4.7%** | 810,465 B/s | 0 | 1 |
| 2 | 13 PASS / 0 FAIL | 19,361s | 19,036s | **1.7%** | 787,201 B/s | 0 | 1 |
| 3 | **12 PASS / 1 FAIL** | 19,314s | 15,661s | **23.3%** | 954,577 B/s | 0 | 1 |
| 4 | 13 PASS / 0 FAIL | 19,290s | 17,487s | **10.3%** | 853,764 B/s | 0 | 1 |
| 5 | 13 PASS / 0 FAIL | 19,292s | 17,033s | **13.3%** | 876,651 B/s | 0 | 1 |

**关键点**：run3 不是假失败。四个字段齐全、`record_exit=0`、`attempts=1`、
`stale_after_clear=0`，误差 23.3% 是**真实计算值**。R1 的三档语义没有掩盖它——
`g5_estimate_selftest.ps1` 里专门有护栏断言证明「齐全但真实超标仍 FAIL、不得伪装成 SKIP」。

## 3. 方差根因（读码 + 实测，非推断）

| 环节 | 口径 |
| --- | --- |
| 产品估算（`src/core/util/DiskEstimate.h`） | `max(0, free - stop) / (total_kbps × 1000/8)`；`total_kbps` = 配置码率 6000 + 音频 192 = 6192 kbps ≈ **774,000 B/s** |
| 用例对照（`g5_storage.ps1` M8-05 段） | `measuredBytesPerSec = bytes_written / wall_seconds`（**10s 短窗口的实测写入速率**）；`expected = (free - 128MB) / measuredBytesPerSec` |

估算侧是**配置码率**（恒定），对照侧是**短窗口瞬时写入速率**（含 CBR/VBR 波动、容器开销、
画面内容变化）。5 次实测码率 787 ~ 955 KB/s，围绕 774 KB/s 波动 **−1.7% ~ +23.3%**；
误差判据几乎等价于「实测码率偏离配置码率的幅度」，而 20% 阈值正好落在这段波动区间内。
所以同一产品、同一用例会在 1.7% 与 23.3% 之间抖动——**判据不可复现**。

这与 `docs/12` 的 M3-04#2 同族：不是实现错，是「拿什么当对照」没定义清楚。

## 4. 为什么执行方不能自己定

- 若把对照口径改成配置码率 → 误差恒 ≈0%，等于用产品自己的输入验算产品，失去独立性；
- 若放宽到 ≤25% → 或直接改判据文字，属「为让测试通过而改尺子」，本轮作废；
- 若只挑 4 次绿的报 5 次全绿 → 隐瞒数据；
- 三者都超出执行方权限，须由验收方定义「估算误差」的对照基准与采样窗口。
