## 3. 冻结的含义

**停止的：**
- 不再下发轮次任务卡，不再合并功能/缺陷改动；
- 不新增依赖、不改契约、不动 `verify/` 判据；
- 不修改已发布 tag 与资产。

**保留的：**
- 仓库与文档（`docs/01~28`）作为事实源冻结；
- 已登记未完成项（真机 4 条、`M1-27#1`、矩阵 11 格、性能基线、MP4 恢复）**留在 `docs/22` / `docs/27`，不当作待办空转**；
- `main` 受保护（禁强推/禁删/必过 CI），冻结期间仍能防止误改。

## 4. 恢复开发的条件（任一）

1. **真机到位**：需要 Win10 23H2、NVIDIA、AMD、混合显卡、B 机（`docs/25`）——补齐后可规划 1.0-GA；
2. **0.1 出现阻塞级缺陷**：按 `docs/23 §6` 流程开 `hotfix/*` 分支，出 `0.1.2`；
3. **O0 明确重启**：另起计划，不在冻结态"顺手改一下"。
